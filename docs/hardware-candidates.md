# 노래 모드 장비 구매 후보

작성: 2026-11-19 · 구매 예정: 약 3개월 뒤 (2027-02 무렵)

**결정: Behringer UMC22 + XM8500 + XLR 케이블.** UMC22도 ASIO를 쓸 수 있다(베링거 공식 드라이버 또는 ASIO4ALL).
받으면 WASAPI 독점으로 먼저 측정하고, 필요하면 로컬 전용 ASIO와 비교한다.

## 왜 사는가

- 목표: **반주와 하드튠 목소리를 박자 맞춰 같이 재생·녹음**하기 (노래방 완성본).
- 지금 USB 헤드셋(USB Advanced Audio Device)으로 **실측한 실시간 듣기 지연: 약 113 ms**.
  소프트웨어 추정은 16 ms였고, 나머지 약 100 ms는 Windows 공유 출력과 헤드셋 내부에서 생긴다.
  소프트웨어로는 더 줄이기 어렵다.
- 헤드셋 출력을 독점 모드로 열면 클릭음이 거의 나오지 않았다(22개 중 1개 감지). 장비 없이 가는 길은 막힌 것으로 본다.
- 하드튠 자체 지연은 이미 3~6 ms까지 줄였다(Waves Tune Real-Time 0~4 ms, Antares AutoTune 2026 2.5 ms 수준).

## 필요한 것 (네 가지 모두 필요)

| 항목 | 후보 | 비고 |
|---|---|---|
| 오디오 인터페이스 | 아래 표 참고 | 마이크 입력과 헤드폰 출력을 한 장치에서 처리하는 게 핵심 |
| 마이크 | **Behringer XM8500** (XLR 다이내믹) | 방 소음과 헤드폰에서 새는 반주를 덜 받는다. 콘덴서·USB 마이크는 비추천 |
| 케이블 | **XLR 암-수**, 3 m 정도 | XM8500은 보통 케이블이 들어 있지 않다 |
| 헤드폰 | 가지고 있는 **유선** 헤드폰 | 블루투스(JBL Tour Pro 3)는 안 된다. 6.3 mm 변환잭이 필요할 수 있다 |

## 인터페이스 후보

| 우선순위 | 제품 | 본 가격 (2026-11 기준) | 판단 |

| 2 | **Behringer UMC22** | 중고 5만 원 (박스품 / 스크래치품) | 예산 10만 원 안에서 가장 무난. 같은 값이면 박스품 |

| 비추천 | USB 콘덴서 마이크 (예: 마타스튜디오) | — | 지금 헤드셋과 같은 종류(일반 USB 오디오)라 지연 문제를 못 푼다 |

### 공개된 왕복 지연 측정 사례 (사용자가 찾은 자료, 출처 미검증)

| 제품 | 측정값 | 조건 |
|---|---|---|
| UMC22 | 10.7 ms | 버퍼 96샘플, Linux |
| UMC202HD | 6.9 ms | 버퍼 64샘플, Windows |
| Scarlett Solo 3세대 | 같은 조건 자료 없음 | — |
| Scarlett Solo 4세대 | 5.0 ms | 버퍼 16샘플, Windows |

- 조건(버퍼 크기, OS, 아마도 ASIO)이 서로 달라서 그대로 순위를 매길 수는 없다.
- 모두 5~11 ms다. 지금 헤드셋 실측 113 ms보다 10배 이상 낫고, 장비끼리의 차이는 그보다 작다.
- 우리 앱은 ASIO 대신 WASAPI 독점을 쓸 계획이라 Windows 기본 드라이버의 최소 버퍼(이 PC에서 3 ms)에 걸릴 수 있다.
  작은 버퍼(16~64샘플)의 이점을 쓰려면 ASIO 지원이 필요하다. 그때 Steinberg 라이선스를 검토한다.
- Scarlett Solo 4세대는 수치가 가장 좋지만 예산(10만 원)을 넘는다(약 20만 원대 추정).

예상 총액: **UMC22 중고 5만 + XM8500 3~4만 + XLR 케이블 1만 ≈ 9~10만 원**.
Scarlett를 받으면 마이크와 케이블 값(약 4~5만 원)만 든다.

## USB 케이블 모양

- USB-A: PC에 있는 납작한 포트
- USB-B: 정사각형에 모서리가 깎인 모양 (UMC22, UMC202HD). "프린터 케이블"
- USB-C: 작은 타원형 (Scarlett Solo 3세대)

## 살 때 확인할 것

새 제품 (쿠팡 등):
- 모델명이 정확한지 (UM2 / UMC22). "호환"이나 "스타일" 같은 표현이 붙은 상품은 피한다
- 로켓배송 또는 평점 높은 악기점인지, 해외직구·병행수입·리퍼가 아닌지, KC 인증 표시가 있는지
- 리뷰 수, 구성품에 USB 케이블이 있는지

중고 (가능하면 직거래, 노트북 들고 5분 테스트):
1. USB로 꽂았을 때 Windows가 인식하는지
2. 마이크를 꽂고 말하면 입력 막대가 움직이는지
3. 헤드폰 단자로 소리가 잘 나오는지
4. 노브를 돌릴 때 지지직 소리가 없는지
5. 단자를 살짝 흔들어도 소리가 끊기지 않는지

새 제품과 가격 차이가 1~2만 원 이하라면 보증이 있는 새 제품이 낫다.

## 사고 나서 할 일

1. 인터페이스 앞면의 **Direct Monitor를 끈다**. 켜 두면 하드튠 안 된 원래 목소리가 같이 들린다.
2. 실제 지연을 측정한다 (헤드폰 한쪽을 마이크에 대고, 볼륨은 낮게):
   `~/__dev/trap-autotune/scripts/run-windows.sh trap_passthrough list` 로 장치 번호를 확인한 뒤
   `trap_passthrough run --in <마이크> --out <헤드폰> --mode exclusive --out-mode exclusive --measure --seconds 12`
   (공유 출력과 비교하려면 `--out-mode shared`)
3. 측정 결과에 맞춰 앱 엔진을 설정한다: 입출력 모두 독점 모드, 유튜브 반주를 루프백으로 가져오기.
4. 반주와 목소리 싱크 보정(측정한 왕복 지연만큼 반주를 늦춰서 섞기) → 노래방 완성본 저장.
